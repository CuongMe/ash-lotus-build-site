Ash Lotus – Installation Guide

Follow these simple steps to install the Ash Lotus Modlist using Wabbajack.

📦 Installation Instructions

This modlist uses Wabbajack to automate the download and setup process.

🧰 Preparation & Requirements

  • You must own Fallout 4 + all DLCs (except HD Texture Pack) via Steam.
💡 Important: If you own Creation Club content, you should install all of it. Some optional patches and features in Ash Lotus support or enhance CC content if detected.
  • At least 250 GB free space required.
  • Install everything on the same drive as Fallout 4. SSD highly recommended.
  • Accounts needed on Nexus.
  • Optional: Nexus Premium is recommended to avoid manual downloads and speed limits.
  • ReShade for Fallout 4 is supported.
Recommended (Tested by Author) Minimum (Estimated)
💾 RAM 32 GB 32 GB (required)
🧠 CPU Intel Core i9 Ultra 275HX Intel Core i5 or Ryzen 5 1600
🎮 GPU NVIDIA RTX 5070 Ti Laptop GPU (12 GB) RTX 3000 series or higher (12 GB)
💽 Storage SSD with at least 140 GB free space SSD (HDD will cause stutters)
🎮 Performance Stable 60 FPS with all visuals enabled (ENB, ReShade, shadows, etc.) ~30–60 FPS with reduced visuals, ENB off, and lowered shadows

📥 Installation Steps

  1. Download and install Wabbajack (install it to the root of the drive where Fallout 4 is installed).
  2. Open Wabbajack, go to the settings menu (gear icon in the top right), and log in to your Nexus Mods account.
  3. Click “Browse Modlists”, set the filter to Fallout 4, and check “Show Unofficial Lists”.
  4. Search for “Ash Lotus” and click the download (play) icon.
  5. When prompted, choose your installation folder and downloads folder — keep them on the same drive.
  6. Click the Play/Install button and let Wabbajack automate the process.
💬 Note:
If Wabbajack throws an error after installation, simply keep clicking Retry and it will resume. This happens because the modlist includes large texture packs, and occasional hash mismatches may require manual retries.

🔧 Post-Installation Checklist

  • ✅ Install Root Builder: Download Root Builder manually, then copy the folder into your ModOrganizer\plugins directory.
  • 🧩 Apply Ash Lotus MCM Settings: Launch the game, open the MCM Settings Manager, and apply the included Ash Lotus preset.
  • ✨ Optional: Install ReShade: This modlist includes a cinematic ReShade preset with HDR and bloom effects. Enable it in-game to greatly enhance visuals.
  • 📘 Review the Game Guide for gameplay tips and mod mechanics.

📦 If you need help or run into issues, join the Discord Server for support.
